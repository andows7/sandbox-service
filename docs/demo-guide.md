# 平台联调演示指南

所有原 demo 启动入口均已统一为 dev。先启动 Docker、Nacos、MySQL，再分别启动 backend 与 frontend，步骤见 [Windows/Linux 启动指南](startup-windows-linux.md)。

浏览器访问 http://localhost:5173，直接提交代码，无需登录或 Token。前端代理直接连接沙箱后端 8084；后端正常注册 Nacos，dev 不检查网关用户头。

每次打开或刷新页面默认显示正确示例，不自动载入上次保存的代码。需要继续编辑时，点击编辑器工具栏中的“恢复草稿”；当前会话内切换题目或语言仍保留已编辑内容。重置恢复正确示例，已保存草稿及提交记录保留。

建议顺序：C 两数之和提交获得 AC；切换 C++ / Java / Python；修改预期输出得到 WA；语法错误得到 CE；死循环触发 TLE，观察容器容量归零。Ctrl+Space 补全，Enter / Tab 接受，Esc 关闭。

后端 8084 提供 API 与 Swagger，不再托管工作台。502 检查后端与 BACKEND_TARGET，503 检查沙箱容量；若遇到旧的 401，重启后端使最新 dev 配置生效。

提交记录保留本浏览器最近 20 次评测。点击一条记录，测试区域的“提交代码”直接展示那次实际提交的完整源码；下方可展开“当时测试用例”查看标准输入和预期输出。测试结果中的“查看提交代码”也可进入此区域。查看记录不会覆盖当前草稿或用例；未保存源码的旧记录会明确提示。

四语言模板可直接在工作台切换查看；完整状态含义和接口约束见 [API 接口文档](sandbox-service-api.md)。
